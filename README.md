# Jacob_kosinski_profile

Public-facing single-page profile website for Jacob Kosinski with:
- Resume-style experience section
- Scrollable projects section
- Clickable GitHub links for applications and source code

## Run locally

Open `/home/runner/work/Jacob_kosinski_profile/Jacob_kosinski_profile/index.html` directly in a browser,
or serve it from the repo root with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
